# Third-Party Notices

The Git HTTP adapter/provider uses these external runtime dependencies:

| Package | Version | License | Use |
| --- | --- | --- | --- |
| isomorphic-git | 1.42.2 | MIT | Browser-compatible Git objects and smart HTTP protocol |
| @isomorphic-git/lightning-fs | 4.10.3 | MIT | In-memory Git object filesystem |
| memfs | 4.79.0 | Apache-2.0 | Desktop in-memory Git object filesystem |

Their transitive runtime packages and exact versions are recorded in `pnpm-lock.yaml` and in the
CycloneDX SBOM generated by `pnpm run ci`. `pnpm licenses list --prod` reports MIT, Apache-2.0,
ISC, BSD-3-Clause and Zlib licenses across this graph. The Git HTTP provider VSIX bundles the
required runtime code; release packaging includes this notice alongside the provider artifact.

All other production package dependencies are internal `@remotish/*` workspace packages. Build,
test and release tools remain development-only dependencies.
